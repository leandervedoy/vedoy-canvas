# Vedøy Canvas

Et visuelt arbeidsområde for ideer og notater.

## Lokal bruk

```bash
npm install
npm run dev
```

Åpne `http://localhost:3000`.

## Bygg

```bash
npm run build
```

Produksjon: https://vedoy-canvas.vercel.app

## Status

Dette er en fungerende frontend-prototype. Verktøyknapper og notatnavigasjon har lokal UI-tilstand, men permanent lagring, eksport og innlogging er ikke ferdig koblet til backend.
